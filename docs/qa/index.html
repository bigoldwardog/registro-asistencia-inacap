03. Sugerencias de mejora

Recomendaciones propuestas para el equipo de desarrollo.

SG-001 · Formato automático del RUT

Se recomienda implementar un formato automático para el campo RUT durante el registro de usuarios.

Al ingresar los números, el sistema debería incorporar automáticamente los puntos y el guion, sin que el usuario tenga que escribirlos manualmente.

Ejemplo: Al escribir 123456785, el formulario mostraría 12.345.678-5.

Beneficio: Facilitar el ingreso del RUT, reducir errores de formato y mejorar la experiencia del usuario.

Prioridad: Media · Usabilidad
SG-002 · Inicio de sesión

Reemplazar las ventanas emergentes por mensajes de error en rojo dentro del formulario, para llamar la atención del usuario sin interrumpirlo.

Prioridad: Media · Interfaz
SG-003 · Cambiar contraseña

Mover la opción "Cambiar contraseña" al apartado "Información de la cuenta", evitando mantener una sección independiente en el menú.

Prioridad: Media · Navegación
SG-004 · Errores al cambiar contraseña

Resaltar en rojo los campos incorrectos y mostrar mensajes claros cuando las contraseñas no coincidan o no cumplan los requisitos.

Prioridad: Media · Validaciones
SG-005 · Teléfonos internacionales

Agregar un selector de país para permitir distintos prefijos y formatos telefónicos, facilitando el registro de usuarios extranjeros.

Prioridad: Baja · Formularios
SG-006 · Firma digital

Incorporar un botón "Deshacer" que elimine solamente el último trazo realizado, manteniendo el botón "Limpiar" para borrar toda la firma.

Prioridad: Media · Usabilidad
