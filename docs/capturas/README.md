# Capturas del sistema

Capturas de las pantallas actuales con datos ficticios de demostración.

Abre `GALERIA.html` en el navegador para verlas organizadas por actor.

- Asistente: formulario desde el QR y confirmación de registro.
- Anfitrión: creación de sesión, gestión de participantes y firma presencial.
- Administrador: historial, detalle y exportación.
- Acceso compartido: inicio de sesión.

Las capturas no incluyen bases de datos ni credenciales. El QR corresponde a un servidor local de demostración que ya está detenido.
